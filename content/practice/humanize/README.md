# humanize practice tasks

Real bugs fixed in [humanize](https://github.com/python-humanize/humanize), turned into practice
tasks by `research/practice-mode-spike/export_tasks.py`. Each JSON file holds the project's code as
it was just before the fix, the fix's tests, and the tests that must pass. The fix itself is not
included.
